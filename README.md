# KoTA308-Aplikasi-Pengelompokan-Dokumen-Tugas-Mahasiswa
Aplikasi pengelompokan dokumen tugas mahasiswa berbasis Graph-Based Clustering sebagai alat bantu (utility tool) mengefisiensikan proses evaluasi tugas naratif (esai) dengan mengotomatisasi pendeteksian kemiripan substansi dan pemetaan kelompok duplikasi antar-mahasiswa berdasarkan bobot kemiripan makna semantik.
